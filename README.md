# taliban-media-analysis
Corpus analysis scripts for MA thesis on Taliban representation in Russian media

Программный код для анализа корпуса публикаций, использованный в ВКР:

**«Репрезентация движения "Талибан" в российских СМИ после 2021 года:
анализ трансформации медиадискурса в формате дата-журналистского проекта»**

Гюлмамедов А.А., НИУ ВШЭ, Факультет креативных индустрий, 2026.

---

## Структура репозитория

| Файл | Описание |
|---|---|
| `parser.py` | Парсинг HTM-файлов выгрузок из базы данных Integrum |
| `sentiment.py` | Тональный анализ корпуса (модель rubert-base-cased-sentiment) |
| `nominations.py` | Частотный анализ номинаций движения «Талибан» |
| `frames.py` | Автоматическая классификация публикаций по системе фреймов |

## Порядок запуска

1. `parser.py` → на вход: HTM-файлы из Integrum → на выход: `corpus.csv`
2. `sentiment.py` → на вход: `corpus.csv` → на выход: `corpus_sentiment.csv`
3. `nominations.py` → на вход: `corpus_sentiment.csv` → на выход: `corpus_full.csv`
4. `frames.py` → на вход: `corpus_full.csv` → на выход: `corpus_frames.csv`

## Среда выполнения

Скрипты разработаны и протестированы в **Google Colab**.
Для локального запуска удалите строки с `from google.colab import files`
и замените загрузку файлов на `pd.read_csv("имя_файла.csv")`.

## Корпус

Эмпирическая база исследования: 366 публикаций из пяти российских
федеральных изданий (РИА Новости, ТАСС, «Коммерсантъ»,
«Независимая газета», «Новая газета») за период январь 2019 —
декабрь 2024 года. Источник: база данных Integrum.
